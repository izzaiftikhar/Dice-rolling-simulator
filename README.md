# Dice Rolling Simulator

A beginner-friendly Python project that simulates rolling two dice and keeps track of the results.

## Features

* Rolls two dice with random values from 1 to 6
* Calculates the total of both dice
* Stores the results of each roll
* Tracks the highest roll
* Calculates the average roll
* Provides a simple menu to roll, view statistics, or exit
* Handles invalid menu choices

## Concepts Practiced

* Python functions
* Parameters and return values
* `random.randint()`
* Variables
* Lists and `.append()`
* `while` loops
* `if`, `elif`, and `else`
* `break`
* Basic calculations

## How to Run

Make sure Python is installed, then run:

```bash
py dice_rolling_simulator.py
```

Choose an option from the menu to roll the dice, view statistics, or exit the program.
